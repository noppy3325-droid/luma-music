# v0.20 検証記録

検証日：2026-11-11（日本時間）。主端末：Xiaomi 14T / XIG07、Android16 / API36、1220×2712、density520。PCとはUSBでADB接続。端末のシステムバーは既存設定のままです。アプリ内は同梱のNoto Sans JPに統一し、端末のカスタムフォントに依存しません。

## 実装と確認範囲

- Backdrop2.0.1の公開APIを固定して採用。兄弟レイヤーの実記録を使用し、前景をぼかさず背景にブラー・vibrancy・lensを適用。動く画像・文字を通したスクロール前後、4品質、縦横の確認画像を保存しました。
- ライブラリ、専用検索、プレイリストをHorizontalPagerで切り替え、1枚の選択ガラスをドラッグ量に同期。ミニプレイヤーと全面アートワーク画面の形状を補間して開閉します。詳しくは [v5.1画面設計](v51-interface.md) を参照してください。
- 固定ウェイトのNoto Sans JPを使用し、曲名・アーティスト名の1行表示を共通化。Aurioのアダプティブランチャーアイコンと、Media3通知用の小アイコンを追加しました。
- スキャンはストリーミング発見/16曲単位のRoom反映、2並列の基本タグ、必要時だけの詳細・画像へ分離。サイズ+mtimeの差分判定、失敗時の参照保持、キャンセル、明示的な削除確認を検証しました。macOSの `._` AppleDoubleを音楽として登録せず、以前の誤登録は参照だけ取り除きます。
- Room1→2の追加マイグレーションで曲、フォルダー参照、お気に入り、手動歌詞、プレイリストとエントリーの保持を確認。破壊的マイグレーションは使用しません。
- 同じMediaSession/ExoPlayer内にPCM16の実DSPを実装。EQ、ヘッドルーム、幅、タグ/解析キャッシュ、控えめなAutoとDirectのバイパスを備えています。詳しくは [DSP設計](audio-dsp-v020.md) を参照してください。

## 自動テストと実機

単体35件。コア30件、実Media3 AudioProcessorアダプター3件、検索2件。Directのバイト一致、実PCMの周波数応答、モノラル/ステレオ、クリップ・非有限値、バッファ分割、遷移、タグ単位、K重み付け、日本語・英字・全半角の検索を確認します。実機で見つけたEMPTY_BUFFERの自己コピー例外は、失敗を再現する回帰テストを追加して修正しました。

最終署名済みAPKをXiaomi 14Tに上書きして、実機の13ケースがすべて成功しました（127.932秒）。データ移行、スキャン2件、解析、DSP切替、標準再生3件、主要画面、ガラス2件、1.6倍の文字サイズ、ランチャー登録を検証しました。標準再生では合成PCMの44.1/48kHz、実AudioTrack、MediaSession、バックグラウンド中のAurio通知アイコンを確認しました。

画面テストはアプリ内のアクセシビリティ操作とテストから送ったタッチイベントを使用しました。横スワイプとタブ選択の同期、短いドラッグの復帰、上下の開閉、再生と3曲のキューの維持、シーク、歌詞、ライト/ダーク、縦横を検証しました。横置きスタンバイのセンサー分岐はOrientationEventListenerを呼び出して確認しました。文字サイズのテストでは、長い日英混在曲名の1行省略とアクセシビリティへの全文提供を確認しました。

debug / release / AndroidTestの生成、JUnit、Lintが成功しました。Lintはエラー0、警告23、ヒント1でした。以前と同じ開発用鍵でrelease APKを署名し、アプリ名 `Aurio`、アプリID `jp.noppy.lumamusic`、versionName `0.20`、versionCode `20` を確認しました。配布APKにはDEBUGGABLEフラグがありません。

配布ファイル `Aurio-0.20.apk` は67,946,766バイトです。SHA-256は `40177b0eef6d24af2e8bb4ecce3b8285a1f4f1de95728cd1cc88dcfd4cb6430a` です。

## 描画・負荷

最終APKのスワイプ、専用検索、再生画面開閉、キュー、歌詞、サウンド設定を連続操作した区間を `dumpsys gfxinfo` で計測しました。端末が報告したアクティブモードは90Hzでした。1,138フレームで中央値14ms、p9530ms、FrameTimeline jank65フレーム（5.71%）、legacy 68.01%でした。スクリーンショット取得も含む混合区間です。p95は60fpsの目安となる16.7msを超えています。

Release APKの同じガラス検証コンポーネントをinstrumentationから表示し、各品質で先頭へ戻してウォームアップ後、同じ12回の前後スクロールを行います。`dumpsys gfxinfo`をリセットして集計し、中央値/p95、GPU時間、現行およびlegacyのjank値を両方残します。CPUはテスト操作も含むプロセス全体、メモリはその時点のサンプルです。描画専用/音声専用の消費電力を分離した測定ではありません。

初回release測定：Balanced 734frames、中央値15ms、p9520ms、FrameTimeline jank1.63%、legacy58.04%、GPU p9513ms。Off 750frames、中央値15ms、p9521ms、jank1.60%、legacy79.20%、GPU p9515ms。Offの方が遅い値もあり、この単発測定から効果の有無や性能優劣は断定しません。legacyの割合を現行のdeadline指標と同じ意味には扱いません。

Direct→Enhance→Directのrelease実機テストでは、1,042msの観測区間に対してプロセスCPU284ms（起動/UI/テストを含む）。再生位置は進み、再生エラーなし。実AudioTrackは44.1kHz/2ch/PCM16、実ルートは内蔵スピーカー、ビットパーフェクト表示は未確認です。`LumaAudioHealth`でMedia3のunderrunイベントも記録します。聴感の比較試聴、長時間の音切れや熱、電池消費はこの短い無音テストで実証したとは扱いません。

## 未検証・制約

- USB-C EarPods/USB DACの接続抜去、物理再生/音量ボタン、Bluetooth機器の実接続。USB端子はPC接続中で、USBハブ/無線ADBは使用していません。
- DAC/HALの実クロックとビットパーフェクト。OSの能力値、希望ミキサー設定、AudioTrack設定だけでは成功を断定しません。
- HyperIsland固有の実表示、長時間再生、全コーデック、巨大ライブラリ、電池消費、有機EL焼き付き軽減の長期効果。
- 24bit/floatは共通経路の上流でPCM16に変換。DirectはAurioの加工だけをバイパスし、高分解能透過を保証しません。
- LUFSは推定値、ピーク制限はサンプル単位。認証メーター/true-peak/AI復元ではありません。アルバムは曲別ゲート推定値の時間加重平均です。
- API29〜30の不透明フォールバック、API31〜32のブラーのみの分岐はソースとAPIガードを確認していますが、それぞれのOS実機では未検証です。
- 添付に参照画像2点が含まれていなかったため、Now Playingは指示書の構図・配色・操作の記述を基準にしています。
