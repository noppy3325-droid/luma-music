# Luma Music design

添付のAndroid音楽プレイヤー開発指示書 v2.0、およびUSB-C EarPods要件を実装元とする。主対象はXiaomi 14T + Apple EarPods (USB-C)。Android 10以上。Kotlin、Compose、Media3、Room、DataStore、SAFを用いる。

## Approach

標準Media3/MediaSessionServiceを唯一のプレーヤーにし、AudioOutputEngineを標準・USB優先ミキサー・ビットパーフェクト試行のポリシーとして交換する。独自USBドライバーは採用しない。別のPCMデコーダーを作る方式はキュー・メディア操作・フォーカスの二重実装が必要なため今回は採用しない。ユーザーの安定性優先の指定に基づく実装上の選択。

AudioDeviceCallbackでsinkの接続を監視し、AudioTrackの実ルートを別に観測する。接続一覧を現在の出力と誤表示しない。切断した実ルートまたは選択済みUSB経路は即座に一時停止。再接続で自動再生しない。ノイジー通知も処理する。

API 34以上で端末が列挙したAudioMixerAttributesのみ候補にする。サンプルレート・チャンネル・PCMエンコードの完全一致を優先する。44.1/48kHzを固定変換しない。空のAudioDeviceInfo配列は未列挙としてそのまま表示し、具体値を推測しない。拒否・例外・未知形式では希望設定を解除し通常再生に戻る。

ビットパーフェクトは明示的なユーザー選択と音量警告を経て、BIT_PERFECTが列挙された場合だけ試行。ソフトウェア音量1、速度1、無加工PCMのときだけ候補にし、出力設定適用とルートを監視する。AudioTrack設定はHALやDACの測定値ではない。端末外での検証なしに保証表示はしない。

## App

SAFの複数フォルダーを永続許可し、再帰スキャン結果をRoomへ保存。読み取ったURIだけ再生し元ファイルを変更しない。タグの欠損・権限消失をUIに出す。キューと位置はDataStore、プレイリスト・お気に入り・編集歌詞はRoom。大きい見出し、アートグリッド、反射・縁取り付きのガラスパネル、背景アートのブラーを使う。Appleの画像や商標は使わない。

横置きスタンバイはボタンで待機した場合だけ姿勢を監視。明るさ・点灯制御は前面のActivityのみ。戻る・縦姿勢・終了で復帰。再生サービスは継続する。

HyperIslandはXiaomi公式メディア通知仕様を調査し、標準MediaSession通知を使う。OSの実表示を確認できない場合は未検証と報告する。重複通知や対応偽装をしない。

## Verification

JVMでミキサー候補・非対応フォールバック・誤表示防止・切断ルール・LRC・検索正規化をテスト。assembleDebugとlintを実行。接続可能な実機/エミュレーターがあればインストールして動作確認。EarPodsの仕様、HID音量キー、実出力レート、HyperIslandは実機証拠の有無を明示する。
