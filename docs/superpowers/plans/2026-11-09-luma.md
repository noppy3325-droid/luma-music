# Luma Music Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task in this session.

**Goal:** Build an offline Android player with honest standard USB audio handling and an installable APK.

**Architecture:** One MediaSessionService owns ExoPlayer. Pure core policies select only reported mixer formats. Repositories own persistent libraries and settings; Compose talks through a MediaController.

**Tech Stack:** Kotlin, Compose, Media3, Room, DataStore, SAF, Android AudioManager/AudioTrack.

**Spec:** ../specs/2026-11-09-luma-design.md and the supplied v2.0 requirements.

## Global Constraints

- Android 10+; extensions gated by actual support and API level.
- Primary test target: Xiaomi 14T + Apple EarPods (USB-C).
- No invented DAC specifications or bit-perfect guarantee.
- No independent USB Audio Class driver. No network permission in the application.
- Write working source and build APK; hardware-dependent results must be labeled.

## Review Focus

- Empty device capabilities must never become guessed 44.1/48kHz support.
- Rejected mixer settings and route changes must clear stale preferred settings.
- Removing unrelated devices must not interrupt playback; removing active USB must pause.
- Repeated scans and revoked grants must preserve user metadata and show errors.
- Rotation and process recreation must not duplicate playback or restore auto-play.
