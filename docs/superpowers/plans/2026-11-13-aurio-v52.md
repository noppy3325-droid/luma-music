# Aurio v5.2 実装計画

1. Media3のコマンド可否、前後の実アイテム、次に再生される順序をPlaybackControllerから公開する。キューとモードの復元を確認し、実プレイヤーを使って自動進行と手動送りの違いを検証する。
2. ミニプレイヤーの入力を1つの方向判定にまとめる。縦は既存PlayerSheetへ委譲し、横は実キューの隣をプレビューする。リリース時に一度だけコマンドを発行し、実アイテムの更新を待って表示を確定する。
3. Now Playingに再生モードを出し、全面アートから曲情報へのつながり、操作間隔、音量表示を調整する。下の操作領域を測ってライブラリ・検索・詳細リストの末尾余白に渡す。
4. キュー順、方向ロック、端での操作、再生維持、ボトムタブと末尾曲の操作を回帰テストで確認する。署名済みAPK、修正前後の画面、検証条件と未検証項目を記録する。
